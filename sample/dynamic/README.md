# about this 
このディレクトリにある問題は，動的（時刻暦応答問題・過渡問題）に特化しています．

## explicit-method  
陽解法に基づく，動的解析．最適化は未実装．
An transient analysis based on explicit time integration. No optimization.

## opt-differentiate-then-discretize  
陰解法に基づく，線形弾性体を仮定した，動的トポロジー最適化．昔からある手法．[定式化が書いてある論文](https://doi.org/10.1007/s00158-015-1328-7)   

時間離散化前の釣り合い方程式（Ma + Cv + Kd = Fext）を等式制約条件として導入し，随伴問題を得る．
そして随伴問題を解く際に，Newmark-beta法に基づく時間離散化を行い，順解析と類似した手順で随伴ベクトルおよび感度を得る．したがって，"differentiate-then-discretize approach"と呼ばれる． 

目的関数として，以下の3種類を実装．変更するには，コンパイルし直す必要がある．  
  1. ひずみエネルギーの時間積分最小化
  2. 外力仕事の時間積分最小化
  3. ターゲット変位のノルムの時間積分最小化

`正しい感度が得られない可能性あり`


## opt-discretize-then-differentiate  
陰解法に基づく，線形弾性体を仮定した，動的トポロジー最適化．最近提案された手法．[定式化が書いてある論文](https://doi.org/10.1002/nme.6710)  
Newmark-beta法に基づく時間離散化後の平衡方程式およびNewmark-beta法における速度，加速度の関係の3つを等式制約条件として導入．
その後，陰的微分項を消去できるように目的関数を微分すもの．したがって，"discretize-then-differentiate approach"と呼ばれる．
"differentiate-then-discretize approach"と比べ，感度の定式化およびプログラム実装は(かなり)煩雑になるが，こちらの方が精度が良いとされている．[検証している論文](https://doi.org/10.1007/s00158-013-1024-4)

`感度についてはRayleigh減衰なしの場合は検証している`


## opt-discretize-then-differentiate-finite  
陰解法に基づく，有限変形(NeoHooke)を仮定した，動的トポロジー最適化．[定式化が書いてある論文](https://doi.org/10.1002/nme.6710)

数値安定化手法が組み込まれている．[安定化についての論文](https://doi.org/10.1016/j.cma.2014.03.021)

問題設定において空隙-固体を仮定する場合，空隙でメッシュが幾何学的破綻し，Newton-Rahpsonが収束しないという数値不安定問題がある．
そこで，ひずみエネルギーを設計変数[0, 1]に応じて線形弾性体-超弾性体で内挿することにより，空隙を線形弾性体とみなし，数値不安定を回避する．
詳細は論文を読んでほしいが，閾値および閾値付近での傾きを調整するパラメータが必要となる．どの程度の値を取るかは，任意．
また，安定化手法については他にも様々なものが提案されているらしい．

`感度についてはRayleigh減衰なしの場合は検証している`
